# 获客短视频口播脚本（约 60 秒）

## 标题候选

- 客户付了钱，n8n 却一声不吭不发货？这个官方案例模板藏了 4 个致命 bug
- 收款自动发货机器人：模板直接抄 = 收款不发货，我把 4 个 bug 全修了

## 口播正文

你在网上卖数字产品，想用 n8n 搞个「客户付款后自动发货」的机器人——官方模板库里正好有一个，收款链接、查客户、原路发货，看起来开箱即用。

但我实测下来，这个模板**直接导入上线就是事故**：

第一，付款校验节点的两根线**接反了**——有效付款被当无效处理，客户付了钱永远收不到货；

第二，查客户那一步，查不到就**静默断链**——不报错、不告警，钱收了，发货链无声死亡；

第三，查询条件里多了两个等号，手机号永远匹配不上；

第四，支付回调**没有验签**——任何人伪造一条付款成功消息，就能白嫖你的货。

这四个 bug 我全部用断言复现了一遍，也全部修好了。修复版工作流、支付宝当面付的国内收款方案、完整排错文档，都放进了课程包。

**完整课程包（含修复版工作流 JSON）——评论区扣【发货】或【4bug】，发你课程入口。**

## 画面建议

- 0-8s：n8n 模板页截图 +「开箱即用？」大字
- 8-35s：四个 bug 逐一弹出（连线接反动画 / 断链红点 / `==` 高亮 / 伪造 POST 终端画面）
- 35-50s：双跑对照结果（忠实版 outbox 空空 vs 修复版 deliver 全绿）
- 50-60s：课程包文件树 + 暗号引导
